## 自己アピール

2014年からプログラマーとして働き、2016年からフリーランスとして活動しています。
Web、API、DB、インフラ、モバイルまで幅広く経験し、テックリードやアーキテクトも担当してきました。

私が得意なのは、複雑になったシステムや、認識がそろっていない仕様を整理して、開発を進めやすくすることです。
「このままだと変更が難しい」「仕様を知っている人に毎回確認が必要」といった状況で、何が原因なのかを考え、関係者と話しながら設計や進め方を見直してきました。
方針を考えるところから、実際にコードを書いて改善するところまで、自分で取り組めるのが強みです。

また、自分の作業だけでなく、チーム全体が進めやすくなることを大事にしています。
改善したいことがあれば、まず自分で小さく試してからチームに広げたり、メンバーの経験に合わせてタスクを分けたりしています。

### AIを活用した開発での強み

AIを使うときは、何を任せるかを整理し、出てきたものを確かめて、実際の開発につなげることを大事にしています。

- **AIが取り組める形に課題を整理する**

  これまでの仕様整理や設計の経験を活かし、実現したいことや既存の制約、作業範囲を整理してAIに渡しています。開発ルールや設計方針もドキュメントに残し、AIと人間が参照できる形にしています。

- **幅広い開発経験を、設計判断とレビューに活かす**

  画面、API、DB、インフラまで担当してきた経験を活かし、生成されたコードが既存の仕様や設計に合っているかを確認しています。実装やテストコードの生成にAIを使いながら、自分で設計を判断し、レビューしています。

- **繰り返し使える仕組みにする**

  定型業務をスキルやメモリで再利用できる形に整理し、自動化・定期実行できるように整備してきました。毎回の手作業や説明を減らし、自分やチームが開発を進めやすい形にしていきたいと考えています。

AIを使って、自分が担当できる範囲を広げることと、チームが開発を進めやすい仕組みを作ることの両方に取り組んでいきたいです。

## 主な実績

- **AI 前提の少人数開発**: 2〜3 名のチームで、Next.js・DB・AWS CDK・LLM 組み込み（チャット UI、Step Functions による AI ワークフロー）までを担当。Claude Code を 3〜5 セッション並行で動かし、hooks で lint・型チェック・テストを自動実行する仕組みを整えた
- **パフォーマンス改善**: Datadog APM で P95 が 1.0 秒を超えていた API で、約 1.3 秒かかっていたクエリを 0.01 秒以下に短縮
- **API 仕様と実装の整合性**: committee-rails で OpenAPI と実装の乖離を CI で検知できるようにした。別案件では、OpenAPI から API クライアントを自動生成し、約 50 本の API について手書きのコードを 1,000〜3,000 行削減
- **開発環境の改善**: esbuild の導入で、ビルド時間を約 5〜10 分から数十秒に短縮
- **大規模リファクタリング**: 3,000〜5,000 行規模のクラスを、先にテストで振る舞いを固定したうえで、約 1 年かけてレイヤーごとに分解
- **チームへの手法の導入**: DDD・BDD をまず自分の担当範囲で試し、効果を見せてからチームに広げた。フロントエンド・サーバーサイド・QA・デザインで振る舞いを共有できるようにした
